## This project is AI-generated

**exifreader is an AI project.** The source code, tests, fixtures, documentation
and the GitHub configuration in this repository were generated by an AI coding
agent (a large language model), with human direction, review and acceptance.

This file exists so that anyone reading, using, auditing or citing the project
knows how it came to be **before** they rely on it.

publicly documented formats (EXIF/TIFF, JFIF, PNG, ISO-BMFF) and of
observations about real files.

## What this means for you

* **Review before trusting.** Generated code can be subtly wrong, can
  mis-read a specification, or can look correct while handling a corner case
  incorrectly. Treat this as code from an unfamiliar contributor.
* **The tests are generated too.** A passing suite shows the code does what the
  tests assert, not that the assertions were the right ones. The fixtures are
  synthetic, generated by the same project, and are not a substitute for a
  corpus of real-world files.
* **Offset and decode results deserve independent checks.** If you use
  exifreader for forensic or repair work, confirm the important values against
  a second, independent implementation (for example `exiftool`).
* **The project is not audited by a human expert.** It has not been through an
  independent security review. The robustness work described in
  [SECURITY.md](SECURITY.md) was produced by automated analysis (sanitizers,
  fuzzing, differential testing) plus generated fixes.
* **Licensing.** The generated output is released under the [MIT License](LICENSE).
  As with any generated work, its copyright status may vary by jurisdiction;
  the licence is granted by the publisher of this repository.

## Transparency conventions used here

* Commits that were produced with AI assistance carry an `Assisted-by:`
  trailer naming the model/tool, in the style used by the Linux kernel's
  [AI coding assistants](https://docs.kernel.org/process/ai-assistance.html)
  policy.
* Changes to this file that alter the disclosure must be called out in
  [CHANGELOG.md](CHANGELOG.md).

## For contributors

Contributions may be AI-generated, human-written, or a mix. Either way the
[CONTRIBUTING.md](CONTRIBUTING.md) rules apply unchanged: the build must be
warning-clean, the suite must pass, new behavior needs a fixture and an
assertion, and a human is accountable for every pull request that is merged.
Please state in the pull request whether AI tools were used and for what.
